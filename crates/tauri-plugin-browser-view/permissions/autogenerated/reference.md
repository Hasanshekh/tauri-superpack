## Default Permission

Default permissions for tauri-plugin-browser-view

#### This default permission set includes the following:

- `allow-create-tab`
- `allow-close-tab`
- `allow-set-tab-bounds`
- `allow-switch-tab`
- `allow-navigate-tab`
- `allow-eval-script-in-tab`
- `allow-list-tabs`
